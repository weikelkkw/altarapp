# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in The Altar, please
disclose it responsibly:

- **Email:** security@thealtarco.app
- **Subject:** "Security report — <one-line summary>"
- **Encrypt** sensitive details when possible.

Please include:

1. The affected endpoint, page, or component.
2. A clear, minimal reproduction (HTTP request / steps).
3. The impact you believe is achievable.
4. Any logs, screenshots, or proof-of-concept.

We will acknowledge receipt within **3 business days** and aim to provide an
initial assessment within **7 business days**. We do not currently run a paid
bounty program, but we credit reporters in release notes (with permission)
when a fix ships.

**Please do not** publicly disclose the issue, exploit it against real user
accounts, or scrape user data while testing. Authorized testing must stay
within your own accounts.

## Out-of-scope

- Reports generated by automated scanners with no demonstrated impact.
- Missing low-severity HTTP headers that do not lead to a real attack.
- Self-XSS that requires the victim to paste an attacker-supplied payload.
- DoS via volumetric traffic (rate limit testing) — please contact us first.

## Supported Versions

The Altar is a continuously deployed web application. Only the version
currently live at https://thealtar.app is supported.
